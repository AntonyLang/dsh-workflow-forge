Ship the scenario as an installable, publishable package

- packager: exact targetDir output for a checked-in package, npm metadata
  (author, homepage, repository.directory, keywords, publishConfig),
  install/usage/result-handling sections in the generated README
- scripts/build-package.ts: clean, reproducible build of
  packages/scenario-source-brief (validate -> 3 mock trials -> package),
  written to a stable path with a BUILD-SUMMARY.md
- packages/scenario-source-brief: complete DSH plugin package with dsh.bundle,
  cordis.patch.yml, dist/index.js, assets, skills, examples, README, LICENSE
- npm scripts: build:scenario and pack:scenario
- docs/awesome: submission YAML plus the checklist for the community list
  (repo-age gate still applies), releases/v0.1.0 hosts the prebuilt tarball

Verification stays at "packaged": trials ran on the offline mock engine and no
real host install or real-model trial is claimed.
